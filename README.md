# Fouad Dadache

> Personal Portfolio built with Next.js · Deployed on GitHub Pages

## ✨ Stack

- **Framework:** Next.js 14 (Static Export)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Fonts:** DM Serif Display + Inter + JetBrains Mono

## 🎨 Color Palette

| Role | Hex |
|---|---|
| Navy (background) | `#0D1B2A` |
| Very Light Beige | `#FAF8F5` |
| Dark Beige / Gold | `#C4A882` |
| Very Dark Green | `#0D2818` |

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 🏗 Build & Deploy

```bash
npm run build   # outputs to /out folder
```

Push to `main` — GitHub Actions deploys automatically to GitHub Pages.

## 📋 Sections

1. **Hero** — Animated aurora background + typewriter effect
2. **About** — Bio + stats (39 members, 4.5K views, 3 languages)
3. **Skills** — Interactive category cards (Business, Design, AI, Tools)
4. **Experience** — Animated timeline (ECONOVO Student Club)
5. **Education** — Degree + Claude AI 101 Certification
6. **Impact** — Animated number counters
7. **Languages** — Circular progress (Arabic · English · French)
8. **Contact** — Email, Phone, LinkedIn, Location

## 📝 Settings Needed on GitHub

1. Go to **Settings → Pages**
2. Set source to **GitHub Actions**
3. Push to `main` to trigger the first deploy
